# Shahzad Learning Hub design

Personal learning website for Classes 9–12. Show new-logo.png beside the visible name Shahzad Learning Hub. Use a midnight background, pale text, muted blue secondary text and mint buttons. Preserve the supplied logo colours.

Navigation: Home → Class → Chapter → Notes, Cards or MCQs. Class and chapter pages have scoped search. Chapters sort numerically within each subject. Show only prepared chapters; all four classes currently have Chapter 2. Keep test papers outside the website.

The homepage portrait is enlarged and cropped with CSS. Hover or keyboard focus reveals About your teacher; touch users can see the link label. The portrait and Portfolio link open the separate portfolio.

Notes use expandable sections with print controls. Cards flip on click, tap, Enter or Space to show the answer and explanation. Previous and Next remain outside the card. MCQs reveal explanations after selection, highlight the correct option and animate feedback. Both formats support topics, shuffle and local progress.

Use responsive layouts for laptop, tablet and phone, visible focus, labelled controls, live feedback and reduced-motion support. Keep assets local and URLs relative for GitHub Pages. No accounts, analytics or server are required.
